# Awesome-Authentication-As-A-Service

## Top Authentication-as-a-Service (AuthNaaS) Ecosystem



**Curated List of SaaS Products & Open-Source GitHub Projects**  

*Focused on Identity Management, Single Sign-On & Passwordless Authentication*  

**Last updated: March 2026**



This repository tracks notable **SaaS platforms** and **open-source projects** for **Authentication-as-a-Service (AuthNaaS)**. These tools handle user authentication, authorization, session management, SSO, MFA, and identity federation for web, mobile, and enterprise applications.



**Examples** include Clerk, Stytch, Descope, FusionAuth, Auth0, WorkOS, Ory, Hanko, SuperTokens, and Magic (the category leaders).



**Open-source emphasis**: This section is heavily expanded with every major active project for self-hosting, custom identity flows, and transparent authentication infrastructure — ideal for developers, startups, and enterprises building vendor-independent auth solutions.



Contributions welcome! Open a PR to add/update entries. Keep descriptions factual and link to official sites.

## SaaS/Hosted Platforms



- **[Clerk](https://clerk.com/)**  

  Developer-first authentication platform with embeddable UI components, session management, and user management for React, Next.js, and modern frameworks.



- **[Stytch](https://stytch.com/)**  

  Passwordless authentication and identity platform with magic links, OTP, OAuth, and biometric authentication APIs.



- **[Descope](https://www.descope.com/)**  

  No-code/low-code customer identity platform with visual workflow builder, passwordless auth, and B2B SSO capabilities.



- **[FusionAuth](https://fusionauth.io/)**  

  Self-hostable or cloud-hosted auth platform with OAuth, OIDC, SAML, and LDAP support, designed for developers who need control.



- **[Auth0](https://auth0.com/)**  

  Enterprise-grade identity platform (now part of Okta) providing extensible authentication, authorization, and SSO for millions of users.



- **[WorkOS](https://workos.com/)**  

  Enterprise-ready auth platform focused on SSO, SCIM directory sync, and audit logs for B2B SaaS applications.



- **[Ory](https://www.ory.sh/)**  

  Open-source-first identity infrastructure with cloud offering, featuring Kratos (identity management), Hydra (OAuth2), and Keto (authorization).



- **[Hanko](https://www.hanko.io/)**  

  Passwordless authentication platform with passkeys, WebAuthn, and FIDO2 support, designed for modern web applications.



- **[SuperTokens](https://supertokens.com/)**  

  Open-core authentication platform with self-hosted and managed options, offering email/password, social login, and session management.



- **[Magic](https://magic.link/)**  

  Passwordless authentication with magic links and WebAuthn, focused on seamless onboarding and developer experience.



## Open-Source GitHub Projects



- **[Keycloak](https://github.com/keycloak/keycloak)**  

  The leading open-source Identity and Access Management solution for modern applications and services. Supports OAuth 2.0, OIDC, SAML, LDAP, and social login. Apache-2.0 licensed with 36,000+ stars and 1,350+ contributors. 



- **[Zitadel](https://github.com/zitadel/zitadel)**  

  Identity infrastructure with multi-tenancy, self-service, and API-first design. Features OIDC, OAuth2, SAML2, passkeys/FIDO2, and SCIM 2.0. Available as open-source self-hosted or Zitadel Cloud with free tier. 



- **[Ory Kratos](https://github.com/ory/kratos)**  

  Headless, API-first identity and user management system written in Go. Handles login, registration, MFA/2FA, account recovery, and profile management. Scales to billions of users with passkeys, social sign-in, OIDC, and magic links. Apache-2.0 licensed. 



- **[SuperTokens](https://github.com/supertokens/supertokens-core)**  

  Open-source authentication solution with email/password, social login, session management, and user roles. Self-hostable with managed cloud option.



- **[Authentik](https://github.com/goauthentik/authentik)**  

  Flexible identity provider with OAuth2, SAML, LDAP, and proxy support. Provides a modern admin UI and flow-based authentication customization.



- **[Casdoor](https://github.com/casdoor/casdoor)**  

  UI-first identity and access management platform supporting OAuth2, OIDC, SAML, LDAP, and CAS. Includes a built-in admin console and extensive SDK ecosystem. 



- **[Janssen Project](https://github.com/JanssenProject/jans)**  

  Cloud-native IAM platform under the Linux Foundation. Features Auth Server (OAuth/OpenID), Agama low-code identity orchestration, and Cedarling policy decision point. Apache-2.0 licensed. 



- **[MaxKey](https://github.com/dromara/MaxKey)**  

  Leading IAM/IDaaS product supporting OAuth2.x, OpenID Connect, SAML2.0, JWT, CAS, and SCIM. RBAC-based unified permission control with full user lifecycle management. 



- **[Stack Auth](https://github.com/stack-auth/stack-auth)**  

  Open-source Auth0/Clerk alternative with 5,100+ stars. Modern authentication platform designed for developer experience. 



- **[Authorizer](https://github.com/authorizerdev/authorizer)**  

  Fully open-source authentication and authorization solution with no lock-ins. Deploys as a Docker microservice with built-in login page and admin panel. 



- **[Authgear](https://github.com/authgear/authgear-server)**  

  Open-source Auth0/Firebase Auth alternative for consumer authentication. Passwordless login, passkeys, 2FA, and enterprise-grade security with OIDC and SAML support. Apache-2.0 licensed. 



- **[Idenplane](https://github.com/idenplane/idenplane)**  

  Lightweight open-source IAM server built with TypeScript, NestJS, and PostgreSQL. Runs in ~150 MB RAM. Supports OAuth 2.0, OIDC, SAML 2.0, WebAuthn/FIDO2, and SCIM 2.0 with built-in Auth0/Keycloak migration importers. 



- **[Authly](https://github.com/abhiraheja/authly)**  

  Open-source self-hostable IDaaS with OAuth2/OIDC, SSO, MFA, passkeys, social login, and multi-tenancy. Features WhatsApp OTP, BYOK messaging, and white-label login. Drop-in alternative to Auth0, Entra, and Supabase Auth. 



- **[Jackson](https://github.com/boxyhq/jackson)**  

  Enterprise SSO service supporting SAML and OpenID Connect, plus SCIM 2.0 directory sync for automatic user provisioning. 1,500+ stars. 



- **[SSOReady](https://github.com/ssoready/ssoready)**  

  Open-source developer tools for enterprise SSO. Ship SAML and SCIM support quickly with a modern API. 1,200+ stars. 



- **[SimpleSAMLphp](https://github.com/simplesamlphp/simplesamlphp)**  

  Mature PHP application for SAML 2.0 authentication. Widely deployed in academic and research networks. 



- **[OpenAM](https://github.com/OpenIdentityPlatform/OpenAM)**  

  Open access management solution with authentication, SSO, authorization, federation, and entitlements. Enterprise-grade with long history. 



- **[TheIdServer](https://github.com/Aguafrommars/TheIdServer)**  

  OpenID/Connect, OAuth2, WS-Federation, and SAML 2.0 server based on Duende IdentityServer with admin UI. .NET ecosystem. 



- **[ArkID](https://github.com/longguikeji/arkid)**  

  Open-source unified identity authentication and authorization management solution. Supports LDAP, OAuth2, SAML, OpenID with fine-grained permission control and DingTalk/WeChat Work integration. 



- **[Gluu](https://github.com/GluuFederation)**  

  Open-source IAM platform with Passport.js interface for social login and inbound identity federation. 



### Additional Strong Open-Source Options



- **[Caddy Security](https://github.com/greenpau/caddy-security)** — Authentication, Authorization, and Accounting (AAA) plugin for Caddy v2 with OIDC, OAuth 2.0, SAML, and MFA support. 

- **[Keycloak Authorization Services .NET](https://github.com/NikiforovAll/keycloak-authorization-services-dotnet)** — Authentication and Authorization with Keycloak for ASP.NET Core applications. 

- **[Passport.js Strategies](https://github.com/jaredhanson/passport)** — Authentication middleware for Node.js with 500+ strategies including OAuth, OIDC, SAML, and social login.

- **[Spring Security](https://github.com/spring-projects/spring-security)** — Comprehensive authentication and authorization framework for Java applications with OAuth2, SAML, and LDAP support.

- **[Devise](https://github.com/heartcombo/devise)** — Flexible authentication solution for Rails with modular architecture and extensive plugin ecosystem.

- **[Laravel Breeze/Fortify](https://github.com/laravel/fortify)** — Authentication scaffolding for Laravel with 2FA, passkeys, and session management.



**Frameworks for building custom AuthNaaS solutions**: Combine **Keycloak** or **Zitadel** as the identity core, **Ory Kratos** for headless user management, **Jackson** or **SSOReady** for enterprise SSO/SCIM, and **Ory Oathkeeper** for zero-trust access proxy. For lightweight deployments, **Idenplane** offers Keycloak-like functionality in a fraction of the resources.

## Disclaimer



- This is a **community-curated** list — not exhaustive and not an endorsement.

- Self-hosted open-source solutions require proper security hardening, regular updates, and infrastructure maintenance.
